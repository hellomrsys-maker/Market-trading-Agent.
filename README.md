## 1. Core Architectural Mandate

This project strictly adheres to a deeply integrated **6-Language Polyglot Architecture**. The fundamental rule of this repository is that **every single logic module and training script** must be natively implemented across ALL six supported languages to ensure maximum depth, verbatim accuracy, and high-throughput benchmarking.

### Supported Polyglot Stack
1. **Python (A1/T1):** High-level AI Brain & Training API
2. **Java (A2/T2):** Enterprise State Management, Depth Watchdog, Top-Down MTF Governor & Order Book Tracking
3. **C++ (A3/T3):** Engine Core & Zero-Bridge Synchronous Memory (64-byte aligned `AtomicStateVector` structs)
4. **Rust (A4/T4):** Data Processing, SIMD Acceleration, Order Block Displacement Calculators & High-Speed Tick Streamers
5. **Julia (A5/T5):** Quantitative Mathematics, Monte Carlo, Kelly Criterion Optimization, Value Area Modeling & Volatility Pricing Simulators
6. **CUDA/Triton (A6/T6):** GPU Mass Parallel Processing Kernels (Mass Footprint, Pattern, Valuation & Stop-Loss Scanners)

### The Implementation Matrix
*   **The Logic Matrix (A1-A6):** When a trading concept or strategy is introduced, it must be coded 6 times across the entire stack.
*   **The Training Matrix (T1-T6):** Training scripts are distinct from Logic Modules. The training epochs themselves must be built natively in all 6 languages to properly benchmark and train the logic components.
